# Design references

The pictures the Spread layout was designed from, in the design session for
the Strip as Spreads (ADR-0003 as amended, ADR-0004). They are mock-ups of
what a Spread should look like, not the site, and nothing in the site reads
them: they live here and not under `public`, so the live site never serves
them.

- `hero-reference.png`: Home's first Spread, the portrait on a disc.
- `case-study-reference-1.png`, `case-study-reference-2.png`: a Work Spread,
  one Case Study to a screen.
- `skills-reference.png`: the Skills Spread.
- `experience-reference.png`: an Experience Spread, one Role to a screen.
- `contact-reference.png`: the Contact Spread, the form beside the address.

`theme-reference.png`, the earlier mock-up the theme was built from, sits here
on disk too but is git-ignored, as it was under `public`.

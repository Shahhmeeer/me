# Case Studies carry no client names, no screenshots, and no client code

The Salesforce work on this site was done for end clients of Shahmeer's
employers, under contracts he was not a party to. Those contracts normally keep
client identity and deliverables private, and Salesforce screens both leak real
client data and prove nothing, because every org looks the same. So a Case Study
names the employer only, describes the client by industry and size, and shows
its result in words and numbers rather than pictures or code.

This looks like an omission. It is not. Do not "fix" it by adding a client logo,
an org screenshot, or an Apex snippet.
